DTP Zipper Help

DTP Zipper creates ZIP files whose names don't become garbled on Windows or Mac.

  • DTP files use linked files, so DTP Zipper never renames anything automatically
  • Alerts you to unsuitable names, and shows which characters are the problem
  • Alerts you to fonts that break when compressed (such as Type 1), and shows which fonts are affected
  • Doesn't compress when there's an alert
