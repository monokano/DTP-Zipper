About DTP Zipper

What the App Does

When a ZIP file made on a Mac is extracted on Windows, its file names can become garbled. DTP Zipper creates ZIP files whose names don't become garbled on either Windows or Mac.

The ZIP file doesn't include a "__MACOSX" folder, which isn't needed on Windows.

Names Are Never Changed

DTP documents place images and other files as links. Because changing a file name breaks the link, DTP Zipper never changes names automatically.

If a name might turn into different characters, or might not extract correctly, DTP Zipper tells you instead of compressing. Fix the name yourself in the Finder, then update the link in your DTP app. Your original files and folders are never modified.

Note As an exception, characters with separated dakuten or handakuten marks (Japanese voicing marks, stored as combining character sequences) are always composed into single characters in the ZIP file. This doesn't break links in Adobe DTP apps. For details, see Encoding.

Basic Steps

  1. Drop folders or files onto the DTP Zipper window or the app icon.
  2. DTP Zipper checks every name. If there are no problems, it starts compressing.
  3. If problems are found, the Name Check window opens. Fix the names, then click Check Again. If there are only warnings, you can review them and click Continue to compress.
  4. The ZIP file is created in the same folder as the items you dropped.
