Troubleshooting

Common Situations

Names are garbled after extracting
The app used to extract the file may not support UTF-8 ZIP files. Set the encoding to Shift_JIS and create the ZIP file again. For details, see Encoding.
Nothing happens when I drop items
Drops aren't accepted during processing or while the Name Check window is open. Wait for processing to finish, or click Cancel, and then drop the items.
The app quits when compressing finishes
Quit When Done is turned on. To keep compressing more items, turn it off. Double-click the app to open it and change the setting.
Some files are missing after extracting on Windows
Aliases, symbolic links, and invisible items inside folders don't go into the ZIP file. See What Isn't Included in the ZIP File.

When an Error Message Appears

When an error occurs, compressing stops. DTP Zipper doesn't create a ZIP file with items missing.

There are no items to compress.
Appears when nothing can go into the ZIP file, for example when you drop only aliases or symbolic links. Drop the original files or folders.
The item could not be read. / The file could not be read.
The item shown couldn't be read. Check its access permissions and the connection to the server or external disk, then drop it again.
The file changed while it was being compressed.
Another app changed the file during compressing. Check which app is editing the file, then drop it again.
The ZIP file could not be written.
Check the free space and the connection of the save location.
A path is too long to store in a ZIP file.
Use fewer folder levels or shorter names.
