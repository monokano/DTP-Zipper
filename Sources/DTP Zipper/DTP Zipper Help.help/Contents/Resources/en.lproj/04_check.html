Name Check

Before compressing, DTP Zipper checks all the files and folders you dropped, including everything inside the folders. If it finds problems, it lists them in the Name Check window. If there are none, it compresses them right away.

Stops and Warnings

Stop (red icon)
A problem that prevents compressing, such as a name that might change when extracted. You can't click Continue until it's fixed.
Warning (yellow icon)
A problem you can review and then compress anyway. If there are only warnings, you can click Continue.

For what each one means and what to do, see Problems and Solutions.

Reading the List

Name
Shows the name with the same icon as in the Finder. Problem characters appear in red. Emoji appear with a red background. Characters you can't see, such as a trailing space or a control character, appear as a red ▁.
Problem
Describes the problem. An item with several problems takes up several rows.
Show in Finder
Selects the item in the Finder. You can also double-click the row, or right-click it and choose Show in Finder.

If there are both fonts that would break when compressed and problems with names, they're divided into Fonts and Names tabs. Each tab shows the number of items.

Fixing Problems

  1. Click Show in Finder.
  2. Fix the name in the Finder. You can leave the Name Check window open.
  3. Click Check Again. If there are no more problems, compressing starts right away.

Changing the Encoding

While the Names list is showing, you can change the encoding in this window. For example, if ① stopped the check with Shift_JIS, switching to UTF-8 lets you compress.

When you change it, the check runs again automatically. Even if the problems are gone, compressing doesn't start by itself: the window shows "No problems were found." Click Continue to compress.

Buttons

Cancel
Goes back to waiting for a drop without compressing. If the app was opened by dropping items onto its icon, it quits instead. Closing the window does the same.
Check Again
Checks the same items again. If there are no more problems, compressing starts.
Continue
Starts compressing. You can't click it while there are stops.
